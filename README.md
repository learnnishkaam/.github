# learnnishkaam

Interactive developer tutorials and browser tools.

Everything here runs on the client side using WebAssembly. Your code and queries execute in your browser, so data stays on your machine without external servers, signups, or tracking.

The name comes from *nishkaam karma*, the idea of focusing on the work itself rather than commercial distraction.

## Projects

- [learn-duckdb](https://github.com/learnnishkaam/learn-duckdb): In-browser SQL tutorials running on DuckDB-Wasm and Apache Arrow.
